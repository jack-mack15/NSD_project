qui ci sono le configurazioni dei client 200 e 400, sono semplici perché hanno solo interfacce e default route.
#questo è per client 200
ip addr add 192.168.2.2/24 dev eth0
ip route add default via 192.168.2.1

#questo è per client 400
ip addr add 192.168.4.2/24 dev eth0
ip route add default via 192.168.4.1

certificati suo e ca e la chiave.
