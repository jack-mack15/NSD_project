AS300 è un semplice AS come AS200
potresti paragonarli ai router di AS200, ma R302 non fa announcement della rete GW300. non so se è un errore, però michele ha fatto
così ed io ho pensato che non dovrebbe essere raggiungibile normalmente. non so matteo come lo abbia fatto. 
qui non riporto GW300 perché dovrebbe avere tanta robba e quindi forse è meglio se lo metto in un file a parte.
non commento nient altro perché tanto è la solita robba e non ci sta niente di particolare.

#R301
conf t

#interfaces
interface lo
ip address 3.1.1.1/32
interface eth0
ip address 10.3.12.1/30
interface eth1
ip address 10.13.0.2/30

#bgp
router bgp 300
neighbor 10.13.0.1 remote-as 100
neighbor 3.2.2.2 remote-as 300
neighbor 3.2.2.2 update-source 3.1.1.1
neighbor 3.2.2.2 next-hop-self

#ospf
router ospf
router-id 3.1.1.1
network 3.1.1.1/32 area 0
network 10.3.12.1/30 area 0
end
