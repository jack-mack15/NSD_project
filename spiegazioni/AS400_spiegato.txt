AS400 è molto semplice perché ci sta un solo router bgp, infatti la configurazione di R401 è molto semplice. non ho messo ospf poiché
non ci sono altri router bgp (credo che si possa mettere però poi non viene usato, ma non ne sono sicuro, quindi evito).
inoltre fa announcement della rete di R402, ho pensato che questa sia  pubblica.
forse R402 è da ritoccare?
anche per il NAT che applica R402, l'ho impostato solo dall'interno verso l'esterno.

OCCHIO che R402 è un client openvpn quindi anche questo ha in root tutto il materiale per poter utilizzare openvpn. sta tutto nella cartella
/root/client402.

#R401
conf t

#interfaces
interface lo
ip address 4.1.1.1/32
interface eth0
ip address 4.1.2.1/24
interface eth1
ip address 10.34.0.2/30
	
#bgp
router bgp 400
network 4.1.2.0/24
neighbor 10.34.0.1 remote-as 300

end

#R402
#QUI OPENVPN

ip addr add 4.1.2.2/24 dev eth1
ip addr add 192.168.4.1/24 dev eth0

ip route add default via 4.1.2.1

#nat
iptables -t nat -F
iptables -t nat -A POSTROUTING -o eth1 -j MASQUERADE
